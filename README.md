## NEON RAMPAGE

A complete, self-contained pixel twin-stick survival shooter. No build step, no dependencies, no network assets — just open `index.html` through any static server (or run `./start.sh`).

- **Goal:** survive endless waves, blast the swarm, and rescue the yellow civilians for big points.
- **Move:** WASD or the left thumb stick.
- **Shoot:** mouse (hold), arrow keys, right thumb stick, or gamepad right stick. Fire is independent from movement.
- **Pause / mute:** `P` / `Esc` and `M`. Enter starts, pauses, and redeploys.
- **Touch:** left half of the screen is a movement stick, right half is an aim + fire stick. Both are dynamic.
- **Extras:** three lives, extra lives every 25,000 points, wave-clear bonuses, local high score, procedural WebAudio sound, gamepad support, and responsive pixel scaling.
